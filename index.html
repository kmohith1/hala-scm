Shared Data (Google Sheets)

Connect a Google Sheet and every entry is written to it as it happens — so the data survives this browser, and everyone opening the page sees the same numbers. Setup takes about five minutes, once.
1. Create a Google Sheet  ·  2. Extensions → Apps Script  ·  3. Paste the code (button below)  ·  4. Set your own SHARED_KEY  ·  5. Deploy → Web app, Execute as: Me, Access: Anyone  ·  6. Paste the /exec URL here
Entries are queued locally if the connection drops and upload on their own once it returns — nothing is lost by working offline. The page also checks for other people's entries every 45 seconds.
